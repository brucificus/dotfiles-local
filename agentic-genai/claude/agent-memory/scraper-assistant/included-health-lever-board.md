Included Health (remote-first virtual care / healthcare navigation company) careers site includedhealth.com/careers -> Lever, board slug `includedhealth`.

- Public board: https://jobs.lever.co/includedhealth/
- JSON API (no auth, WebFetch/curl friendly, no CSP issues): https://api.lever.co/v0/postings/includedhealth?mode=json
- Per-req detail / Apply page: https://jobs.lever.co/includedhealth/<uuid>
- `createdAt` is epoch ms. `descriptionPlain` + `additionalPlain` hold the JD; pay is a "Zone A/B/C/D: $low - $high" block. Some newer lighter postings omit the qualifications/pay block entirely.

See [[lever-postings-api]] for general Lever mechanics.

Engineering role naming note (as of 2026-08): the Indeed listing "Senior Software Engineer, Fullstack" (React-must full-stack) expired and appears rebranded on Lever as **"Senior Software Engineer, Web"** ("front-end-first full-stack role", Member Experience team). "Senior Software Engineer, Backend" keeps the same title on both. Also seen: "Staff Software Engineer, Product" (Remote). All Engineering reqs are department Engineering / team Software Engineering / location Remote.
