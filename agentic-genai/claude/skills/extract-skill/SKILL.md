# Extract Skill

Extract from the current session such a skill that can be reused by similar invocation agent sessions in the future. If the user's description identifies something that's been done more than once this session, generalize it into a skill that captures the essence of the repeated action or pattern.

Drive the solution space of the extracted skill to use deterministic and repeatable methods if at all possible.

Make sure the skill contains all the information needed for it to be applied effectively in future sessions, including any prerequisites, inputs, outputs, and the control surface along its seam.
